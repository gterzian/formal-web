# Skills

Index and conventions for the skills in `.agents/skills/`. `AGENTS.md` points
here for everything about skills.

| Skill | Path |
| --- | --- |
| `web-standards` | `.agents/skills/web-standards/` |
| `readme-chain` | `.agents/skills/readme-chain/` |
| `browser-debug` | `.agents/skills/browser-debug/` |
| `startup-page-test` | `.agents/skills/startup-page-test/` |

## Layout

Skills with tools are normal Node apps; nothing is bundled or vendored:

```text
.agents/skills/<name>/
├── SKILL.md          required
├── package.json      only when the skill has dependencies
├── package-lock.json generated by npm install
├── scripts/          plain .mjs implementation
└── references/       optional detail
```

- `SKILL.md` frontmatter carries `name` (lowercase letters, numbers and
  hyphens, matching the directory), the routing `description` (what the skill
  does and when it applies, at most 1,024 characters), and `compatibility`
  only for requirements specific to that skill. This file owns the global Node
  requirement.
- The index above lists only name and path; the routing text is each
  `SKILL.md` description.
- Declare dependencies in the skill's `package.json` and install them with
  `npm install` in the skill directory. Never commit `node_modules` or a
  bundled dependency, and do not add a build step.
- `scripts/` holds code, `SKILL.md` holds the workflow and commands, and
  `references/` holds detail loaded on demand. Apply the "Documentation
  Chain" rules in `AGENTS.md` to these files: each fact lives at one level,
  and a lower level points to the file that owns a fact instead of restating
  it.
- A skill that must not be auto-selected sets
  `disable-model-invocation: true`.

## Adding a skill

1. Create `.agents/skills/<name>/SKILL.md`.
2. Put implementation in `scripts/` as plain `.mjs`; add a `package.json`
   and run `npm install` only if the skill has dependencies.
3. Add the skill to the index above.

## Install

Node.js 20.18.1 or newer. Skills with a `package.json` need their dependencies
installed once:

```bash
(cd .agents/skills/web-standards && npm install)
(cd .agents/skills/browser-debug && npm install)
```

Bump a skill's dependencies in its `package.json` and run `npm install` again.
`startup-page-test` has no dependencies.

## Run

Run a skill's script (where it has one) with `node`. The command lists in each
`SKILL.md` use paths relative to that skill's directory; use the full path from
the repository root when running from there.
